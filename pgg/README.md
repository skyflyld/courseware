## 真题原文库（2026-09 重建）

四份考生提供的扫描件（10 页/年，纯图像、无文字层）逐页 OCR 转录，**德语原样、题号原样、不翻译不改写**。

OCR 管线：视觉逐字转录模型**双遍独立识别**（1500px / 2000px 两档渲染），行级交叉核对，疑点做局部放大定向复读；
无法确证处标 `⚠️` 并附另一种读法，整理者补注用 `〔整理者注：…〕`，卷面印误照录并加注（如 2023 年 Ⅳ 印作 45%，四年中其余三年为 35%）。

校勘发现（2026-09 与扫描件逐字核对）：2024 年 Ⅳ-A 第 46 题原句 „________ auf die glatte Straße, damit ihr nicht hinfallt.“ 选项 a. Achte b. Achtet c. Achten Sie，答案为 **b) Achtet**（旧版分析记作 „Achten Sie“，已更正）。

```
Ⅰ Diktat 10%        听写：A 填空听写（8空） + B 全文听写
Ⅱ Hörverstehen 20%  听力：Teil1 6 短对话（听1遍）+ Teil2 4 短文（听2遍）
Ⅲ Leseverstehen 20% 阅读：Teil1 标题匹配 21-24 + Teil2 长文 A/B/C
Ⅳ Grammatik 35%     语法词汇：A 选择41-50 / B 完形51-70 / C 词汇71-90 / D 改写91-95 / E 改错96-100
Ⅴ Schriftlicher Ausdruck 15%  写作：图表描述 150-180 词
```
